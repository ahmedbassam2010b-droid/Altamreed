# بوابة التمريض | Bawabet Al Tamreed

منصة تعليمية عربية لطلاب التمريض، مبنية بواجهات HTML وCSS وJavaScript، مع Firebase Authentication وCloud Firestore.

## هيكل المشروع

- صفحات HTML الأساسية في جذر المستودع.
- `assets/images/` للصور والشعارات والصور المستخدمة داخل الواجهات.
- `assets/icons/` لأيقونات SVG.
- `assets/illustrations/` للرسوم التوضيحية.
- `assets/fonts/` للخطوط المحلية عند إضافتها.
- `css/` لملفات التنسيق المشتركة والمتخصصة.
- `js/` لوحدات JavaScript.
- `simulations/` للمحاكاة العملية وسيناريوهاتها.
- `content/` لمحتوى المناهج الحقيقي للسنوات الدراسية الثلاث.

## الصفحات الحالية

- `index.html`: الصفحة الرئيسية.
- `login.html`, `register.html`, `forgot-password.html`: الدخول وإنشاء الحساب واستعادة كلمة المرور.
- `dashboard.html`: لوحة الطالب.
- `subjects.html`: المواد المنشورة من Firestore.
- `subject.html`: الدروس المنشورة داخل مادة محددة.
- `admin.html`: واجهة إدارة أولية، وليست نظام صلاحيات إداريًا مكتملًا.
- `404.html`: صفحة غير موجودة.

## التشغيل

شغّل المشروع عبر خادم صفحات ثابتة يدعم وحدات JavaScript (ES modules)، وليس بفتح ملفات HTML مباشرة من نظام الملفات. صفحات المصادقة والمحتوى تحتاج اتصالًا بالإنترنت للوصول إلى Firebase SDK وخدمات Firebase.

## البيانات والأمان

- بيانات المواد والدروس المنشورة تُقرأ من مجموعتي `subjects` و`lessons` في Cloud Firestore.
- لا تضع بيانات مناهج افتراضية أو بيانات تجريبية داخل ملفات JavaScript.
- لا تُضمّن أسرارًا إدارية أو صلاحيات موثوقة في الواجهة الأمامية.
- يجب ضبط صلاحيات الوصول الفعلية من Firebase Security Rules؛ إخفاء الروابط أو حماية الواجهة وحدهما لا يكفيان.
- لم تُغيّر هذه المرحلة إعدادات Firebase أو مجموعات Firestore أو قواعدها.

## ملاحظات التطوير

الصفحات والميزات التي تعتمد على مخطط بيانات لم يُعتمد بعد لا تُنشأ كواجهات شكلية. أضفها بعد توثيق الحقول والعلاقات المطلوبة واختبارها مع بيانات Firestore الفعلية.
