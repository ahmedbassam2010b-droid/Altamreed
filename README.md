# بوابة التمريض | Bawabet Al Tamreed

منصة تعليمية عربية RTL مبنية بـ HTML وCSS وJavaScript وFirebase Authentication وCloud Firestore.

## الصفحات
- دخول الطالب: `login.html`، إنشاء الحساب: `register.html`، استعادة كلمة المرور: `forgot-password.html`.
- مساحة الطالب: `dashboard.html`، الملف الشخصي، المواد، الدروس، المكتبة، المحفوظات، مخطط المذاكرة، التحدي اليومي، المراجعة السريعة، الاختبارات والنتائج، المحاكاة، المجتمع، الرسائل، الإشعارات، ولوحة المتصدرين.
- دخول الإدارة: `admin-login.html`.
- لوحة الإدارة: `admin.html`.

## المحتوى الدراسي
لا توجد مواد أو دروس افتراضية. المدير هو من ينشئ السنوات والمواد والدروس وينشرها من لوحة الإدارة. مجلدات `content/first-year` و`second-year` و`third-year` مهيأة لإضافة ملفات المناهج الفعلية عند توفرها.

## إدارة المحتوى
لوحة الإدارة الحالية تتيح إنشاء وإدارة:
- المواد الدراسية والدروس.
- الاختبارات متعددة الأسئلة، والاختيارات، والإجابة الصحيحة، والدرجات.
- موارد المكتبة العلمية.
- الإشعارات.
- بطاقات المراجعة والتحديات اليومية.
- سيناريوهات المحاكاة.
كما تعرض حسابات الطلاب ورسائلهم ومشاركات المجتمع، وتسمح بإلغاء نشر العناصر أو حذفها.

## الاختبارات وحدود التصحيح الحالي
التصحيح الفوري الموجود حاليًا ينفذ في المتصفح اعتمادًا على بيانات الاختبار التي تُحمّل للطالب. هذا مناسب للاختبارات التدريبية، لكنه **ليس نظام تصحيح آمنًا ضد التلاعب** لأن مفتاح الإجابة يصل إلى المتصفح. لا تستخدمه لامتحانات رسمية أو نتائج عالية المخاطر. التصحيح الموثوق يحتاج Backend موثوقًا (مثل Cloud Functions أو خدمة خلفية أخرى) يحفظ مفتاح الإجابة ويحسب النتيجة بعيدًا عن جهاز الطالب. خدمات Cloud Functions تتطلب التحقق من خطة Firebase والتكاليف قبل تفعيلها؛ لا تفعل ترقية مدفوعة دون موافقة صاحب المشروع.

## Firebase
- إعدادات المشروع في `js/config.js`.
- قواعد الأمان المقترحة في `firestore.rules`.
- وجود مستند `admins/{uid}` هو شرط صلاحية الإدارة. لا تسمح للواجهة الأمامية بإنشاء أول مدير.
- بعد مراجعة القواعد، انسخها إلى Firebase Console > Firestore Database > Rules ثم انشرها. رفع الملف إلى GitHub وحده لا ينشر قواعد Firestore.
- لا تحذف مستند المدير الموجود ولا تغيّر قواعد Firebase المنشورة قبل مراجعة النسخة الحالية ومقارنتها بهذه القواعد.

## مجموعات Firestore
`admins`, `users`, `publicProfiles`, `subjects`, `lessons`, `exams`, `examAnswerKeys`, `examAttempts`, `examResults`, `library`, `notifications`, `revisionCards`, `dailyChallenges`, `challengeAnswerKeys`, `challengeResponses`, `simulations`, `studyTasks`, `communityPosts`, `messages`.

## التشغيل
شغّل الموقع عبر استضافة صفحات ثابتة تدعم ES Modules وHTTPS، ثم اختبر الدخول والقراءة والكتابة على Firebase. يلزم اختبار قواعد Firestore المنشورة مع حساب طالب وحساب مدير قبل اعتماد النسخة النهائية.
